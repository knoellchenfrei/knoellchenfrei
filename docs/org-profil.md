## knoellchenfrei

**Wo Parken gerade etwas kostet, wie viel, und wie lange man stehen darf.**
Aus den amtlichen Geodaten der Städte — nicht geschätzt, nicht abgeschrieben.

Dazu: wo zuletzt das Ordnungsamt gesehen wurde, gemeldet von denen, die es
gesehen haben.

| | |
| --- | --- |
| **Städte** | Berlin, Hamburg |
| **Läuft** | im Browser, auf dem Homescreen installierbar, offlinefähig |
| **Stand** | geschlossener Testbetrieb — noch nicht öffentlich |
| **Lizenz** | MIT. Kein Abo, keine Werbung, kein Tracking. |

### Woher die Daten kommen

Aus den offenen Geodatendiensten der Länder: der
Geodateninfrastruktur Berlin unter *Datenlizenz Deutschland Zero 2.0* und der
Freien und Hansestadt Hamburg unter *Datenlizenz Deutschland Namensnennung
2.0*. Kartenkacheln von OpenStreetMap unter ODbL.

Was die Quellen nicht sagen, behauptet die App nicht. Nennt ein Datensatz eine
Preisspanne statt eines Preises, steht dort eine Spanne. Gilt eine Regel, die
sich nicht abbilden lässt, steht dort „unsicher" und ein Verweis auf den
Automaten. **Verbindlich ist die Beschilderung vor Ort** — das sagen die
Quellen selbst, und die App sagt es auch.
